# 💳 第三方金流（綠界 ECPay / LINE Pay）串接架構藍圖

本文件規劃全站線上金流閘道器的串接架構、交易時序與防禦機制，支援側滑購物車結帳。

---

## 🏗️ 系統交易時序圖 (Sequence Diagram)

```
[使用者 / 購物車] ──(1. 提交訂單金額)──> [Agent 1: POST /api/orders]
                                                  │
                                       (2. 建立訂單 / Pending)
                                                  │
                                                  ▼
[使用者瀏覽器] <──(3. 跳轉金流頁面)── [綠界 ECPay / LINE Pay]
      │                                           │
(4. 使用者完成付款)                               │
      │                                           ▼
      └─────────────────────────────────> (5. 異步伺服器回調 Webhook)
                                                  │
                                        (6. 驗簽 CheckMacValue)
                                                  │
                                                  ▼
                                       [更新訂單狀態為 Paid]
```

---

## 🛡️ 資安防禦原則

1. **金額伺服器端重算**：
   * 前端購物車傳入的商品 ID 與數量，後端（Agent 1）必須對照 `doterra.csv` 之官方建議零售價重新計算總額，**絕不信任前端傳來的單價或總金額**。
2. **CheckMacValue 簽章校驗**：
   * 綠界回調通知必須使用 `HashKey` 與 `HashIV` 進行 SHA256 壓碼驗證，防範假造付款成功通知。
3. **冪等性處理 (Idempotency)**：
   * 同一筆訂單重複收到付款通知時，必須保證狀態不被覆蓋，庫存不被重複扣除。
