# 📦 Agent 4：商品目錄、定價與內容文案目錄 (`/catalog/`)

本目錄為 **Agent 4** 專屬維護範圍，掌管全站 131 款精油母體資料庫、多特瑞單一「建議零售價」、容量規格、三大位格與合規自然醫學文案。

---

## 📌 負責職責

1. **精油資料庫母體管理**：
   * 維護 `doterra.csv`：包含 131 款精油名稱、英文學名、標準容量、建議零售價、三大位格（中柱/右柱/左柱）、使用方式（薰香/塗抹/內服）與稀釋指南。
   * 維護 `indicator_cards.csv`：包含 12 張指示象徵卡。
2. **單一定價與容量標準**：
   * **單一建議零售價**：全面對等多特瑞台灣官方「建議零售價」（消滅會員價雙軌定價）。
   * **容量規格**：嚴格落實官方標準規格（15ml / 5ml / 10ml 滾珠 / 115ml 基底油）。
3. **法規遵循與自然醫學審定**：
   * 確保所有調息箋與說明文字採用國際通用、合規低爭議之「**自然醫學**」用語。
   * **嚴格杜絕醫療法規爭議詞彙**（嚴禁出現：古法中醫、名醫、治癒、療效、處方治療）。
4. **目錄資料同步管線**：
   * 執行 `catalog/sync_catalog.py`：將 CSV 母體自動編譯並同步至 `static/oils-catalog.json`，供前端圖鑑與側滑購物車零延遲讀取。

---

## 🚀 同步操作指令

```bash
# 當修改 doterra.csv 後，執行此指令同步至前端 JSON
python catalog/sync_catalog.py
```

* **不得修改** `/api/` 後端伺服器程式碼與 `/components/` 前端切版樣式。
* 任何商品新增或定價異動，必須確保符合多特瑞官方建議零售價與規格標準。
